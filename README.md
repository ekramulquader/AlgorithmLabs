# Algorithm Labs

This repository contains C++ implementations of various algorithms, data structures, and concepts covered in the Algorithms lab course.

It includes the lab assignments and practical programs I worked on for learning, practice, and academic reference. More topics and implementations will be added over time.

## Language

- C++

## Compilation

Make sure a C++ compiler such as GCC is installed on your system.

Compile a program:

    g++ filename.cpp -o program

Run the program:

    ./program
